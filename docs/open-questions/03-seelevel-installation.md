# SeeLeveL tank, LPG, and OEM-panel integration

- Measure usable vertical sender area on fresh, gray, and black tanks before purchase.
- Test the Minnie Winnie ASME LPG sender's resistance range against BTP7 requirements.
- Determine whether generator, hour meter, water heater, water pump, and OEM tank monitor controls are separate components or one PCB.

The desired physical result is a clean SeeLeveL faceplate that retains required generator and water controls. Mopeka remains a fallback only if the existing LPG sender is incompatible.
