# Inverter independence and Raspberry Pi hardware

The inverter remains independent of dashboard architecture; Renogy PUH, Xantrex, or another unit must not alter the normalized UI contract.

Select and validate the Pi model, 7–10 inch capacitive display, mounting location, enclosure, battery-backed DC-DC supply, kiosk start, display sleep/wake, graceful shutdown, filesystem protection, and stored-RV power consumption.
