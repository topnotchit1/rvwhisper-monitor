# PowerMon-5S direct BLE feasibility

Verify whether the RVM3 and Raspberry Pi can both consume PowerMon-5S BLE telemetry reliably. Measure update frequency, reconnect behavior, and whether the faster current/watt feed materially improves the wall display.

If concurrent consumers are unreliable, keep RV Whisper as the only PowerMon source. Do not make direct BLE mandatory for MVP.
