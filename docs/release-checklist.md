# Public release checklist

- [ ] No `.env`, database, bytecode, logs, payload captures, or real sensor map is tracked.
- [ ] Search finds no personal names, email addresses, home-directory paths, device IDs, credentials, or precise location data.
- [ ] Generated images contain no identifying metadata.
- [ ] Git author email uses a GitHub `noreply` address or an intentionally public address.
- [ ] Production UI build succeeds.
- [ ] Backend normalization, freshness, SQLite, and API smoke tests succeed.
- [ ] Pi installer and verification scripts pass shell syntax checks.
- [ ] Demo mode passes before credentials are entered or live mode is enabled.
- [ ] RV Whisper remains described as the independent alerting authority.
